# Daily DSA Practice (Java)

## Overview

This folder contains my daily Data Structures and Algorithms (DSA) practice using Java. I regularly solve problems from platforms like LeetCode and other coding websites to improve problem-solving skills and prepare for technical interviews.

## Goals

- Strengthen DSA concepts
- Improve problem-solving speed
- Prepare for coding interviews
- Maintain consistency with daily practice

## Platforms Used

- LeetCode
- GeeksforGeeks
- CodeStudio / Coding Ninjas
- HackerRank

## Structure

Each file represents a problem solved on a particular day.

Format:

```
Day-X_ProblemName.java
```

Example:

```
Day-1_TwoSum.java
Day-2_ValidParentheses.java
Day-3_BinarySearch.java
```

## Topics Covered

- Arrays
- Strings
- Linked List
- Stack & Queue
- Trees & Graphs
- Recursion & Backtracking
- Dynamic Programming
- Searching & Sorting

## Approach Followed

- Understand the problem
- Write brute force solution
- Optimize approach
- Code in Java
- Test with edge cases

## Progress Tracking

- Daily commits

- Gradual increase in difficulty (Easy → Medium → Hard)
